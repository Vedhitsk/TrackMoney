- (decision) SQLite is the absolute source of truth. Zustand acts as a read cache and ephemeral UI state container (like transaction drafts). The background task writes directly to SQLite and signals the UI via DeviceEventEmitter. The UI must respond by re-querying SQLite, never by receiving data directly through the event.
- (decision) The AI and Regex parsers are strictly pure boundaries with no database access. They take raw SMS strings and return standardized parsed objects. A separate Coordinator/Ingestion layer handles DB enrichment (e.g., merchant lookup) and persistence.
- (decision) Parsers implement a unified interface and receive raw SMS strings from the Coordinator. Data masking/redaction is the strict responsibility of Remote parser implementations (Groq/Gemini) before network transit. Future Local/On-device SLM implementations (e.g., Gemma) may bypass masking.
